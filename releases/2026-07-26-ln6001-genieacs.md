# LN6001 QSDK 12.2 GenieACS First-Inform Bundle

Release date: 2026-07-26

This release publishes the complete Linksys Velop WRT Pro 7 (LN6001) package
set used by the verified GenieACS first-Inform flow.

The `bbf-agent` package is required for the proven LN6001 flow. It adds:

- `/etc/bbfdm/services/core.json`
- `/etc/bbfdm/services/icwmp.json`
- `/etc/bbfdm/services/sysmngr.json`
- `/usr/share/bbfdm/micro_services/sysmngr.json`
- BBF runtime plugin links
- LN6001 UCI identity defaults
- safe ACS configuration and first-Inform smoke commands

Version `26.4.0726` maps the public helper inputs `username=` and
`password=` to the iCWMP UCI options `cwmp.acs.userid` and
`cwmp.acs.passwd`.

## Install Order

```sh
opkg install ./mxml_2.12-1_arm_cortex-a7_neon-vfpv4.ipk
opkg install ./bbfdm_7.5-1_arm_cortex-a7_neon-vfpv4.ipk
opkg install ./icwmp_7.5-1_arm_cortex-a7_neon-vfpv4.ipk
opkg install ./bbf-agent_26.4.0726_all.ipk
```

Follow the complete guide:

[Connect Linksys LN6001 to GenieACS](https://github.com/ikm-san/icwmp-ln6001/blob/main/GENIEACS_SETUP.md)

## No Model XML Upload

A separate LN6001 XML file is not required for GenieACS registration. The
package set uses UCI configuration, BBF JSON service descriptors, the LN6001
`sysmngr.json` TR-181 mapping, and Mini-XML for internal CWMP SOAP messages.

## Proven Scope

The LN6001/GenieACS lab proof reached a successful Inform response, RPC-method
exchange, HTTP 204 completion, and a GenieACS device record with an advancing
`_lastInform` timestamp.

This release does not claim full TR-069 management parity:

- ACS-initiated connection requests are not proven.
- The CWMP firewall helper remains non-mutating.
- XMPP/LWN is disabled.
- Generic router configuration, package operations, raw UCI, and shell commands
  are not exposed as arbitrary TR-069 writes.
- GenieACS tasks may wait for the next periodic Inform.
